# 🎯 班級智慧作業清點與錯題訂正系統 — 副本快速部署指南

這套範本專為「建立副本」與獨立推廣打造。後端程式碼已設定為**自動綁定當前試算表 ID**，任何人建立副本後不需修改程式碼即可部署使用。

---

### 📂 檔案架構說明

- `Code_Template.gs`: 後端核心程式碼（包含純按鈕點收、QR碼掃碼、錯題訂正與催繳矩陣 API）
- `Index_Template.html`: 預設主頁面（純按鈕點收 + 全班缺交催繳矩陣 + 擴充選單）
- `Scanner_Template.html`: 📱 QR碼相機速掃工具
- `Correction_Template.html`: ✏️ 錯題訂正與銷案矩陣系統

---

### 🚀 15 秒快速部署流程

1. **建立 Google 試算表副本**：
   - 開啟試算表範本，點選 **`檔案`** ➔ **`建立副本`**。

2. **貼入 Apps Script 程式碼**：
   - 在新試算表中點選 **`擴充功能`** ➔ **`Apps Script`**。
   - 將 `Code_Template.gs` 貼入 `Code.gs`。
   - 建立 3 個 HTML 檔案（`Index`、`Scanner`、`Correction`），分別貼入對應內容。

3. **發布 Web App**：
   - 點擊右上角藍色 **`部署`** ➔ **`新增部署`**。
   - 種類選 **`網頁應用程式`**：
     - **執行身分**：`我` (Me)
     - **誰有存取權限**：`所有人` (Anyone)
   - 點擊 **`部署`** 並授權存取，即可取得專屬網址！
